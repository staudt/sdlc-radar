Current picture

The market signals that keep repeating across recent editions.

  • Testing is becoming a control system
    Pass rate alone is no longer enough. Stronger setups add independent validation, trajectory review, mutation style checks, and policy gates.
  • Agent workflows matter more than single models
    Separation between reasoning, execution, and approval is becoming a core architectural pattern.
  • QA is moving earlier
    Specification enrichment and requirements formalization are becoming higher value than only downstream automation.
  • Narrow autonomous agents are winning first
    Consistency checking, CI investigation, and focused review agents look more practical than broad autonomous QA claims.

Top consulting questions

High value prompts for discovery and assessment work.

  1. Are requirements explicit enough for agents to act on safely?
  2. Can generated code and generated tests be independently validated?
  3. Does CI expose useful evidence for agent investigation?
  4. Are agent permissions separated from privileged execution?
  5. Where can narrow agent workflows reduce test maintenance or increase discovery quality?
