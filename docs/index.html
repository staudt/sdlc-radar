About

Main signal

AI native SDLC is becoming a governed workflow, not a single model.

The strongest implementations separate agent reasoning, deterministic execution, independent verification, and privileged approval. QA is increasingly the control layer that makes that autonomy trustworthy.

Current picture

Patterns that keep repeating across recent editions.

  • Testing is becoming a control system. Pass rate alone is no longer enough.
  • QA is moving earlier. Specification quality increasingly determines agent quality.
  • Narrow agents are winning first. Focused investigation and consistency checks are proving more useful than broad autonomy claims.
  • Permissions are architecture. Reasoning and privileged execution increasingly need separate trust boundaries.

Production now

Playwright CLI for agents

Browser automation is becoming a native capability for coding and testing agents. Playwright CLI gives agents a compact, deterministic interface for inspection, test generation, execution, diagnosis, and repair without forcing every interaction through a large MCP tool surface.

Why it matters

This is a practical bridge between coding agents and mature browser automation. It also reinforces a broader pattern: use deterministic tools underneath the agent and reserve model reasoning for interpretation and decision making.

Agentic SDLC

The durable pattern is a governed workflow: agents handle interpretation and planning, deterministic systems handle reproducible execution, and policy boundaries control privileged actions.

  • Use agents where reasoning is valuable, not as a replacement for every deterministic step.
  • Separate read and reasoning privileges from write and deployment privileges.
  • Favor focused workflows that can be observed and evaluated over broad autonomy claims.
