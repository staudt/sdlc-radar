Signals

GovernanceExperiment now

Merge approval is becoming an agent decision, governed by a policy file in the repository.

Anthropic launched Claude Ship on Nov 23 for Claude Team and Enterprise organizations on GitHub (TechCrunch, 9to5Mac). Code Review (generally available) checks each pull request. PR Steward (beta) pushes fixes for failing CI, merge conflicts and review feedback. Claude Approvals (beta) approves routine changes or requires named people to sign off, following a policy file the team keeps in the repository.

Defaults are cautious (setup docs, policy reference). A new policy starts in observe mode: the check reports what Claude would decide, approves nothing and normally passes. It blocks a merge only once made a required check in GitHub. Anthropic warns the agents can miss bugs and security flaws.

Cognition's Devin Bots (Friday) and Copilot's adaptive review depth (Thursday) moved the same way last week.

Why it matters: The approval policy now decides what ships without a person. Treat it like branch protection: review changes to it, keep sensitive paths on named people, and compare observe-mode decisions with your reviewers' first.

"When an AI agent can approve pull requests, its policy file is your review process. Put it under change control and test it in observe mode before it can merge anything."
Anthropic Claude Ship launch and Claude Approvals docs, Nov 23, 2026

GovernanceExperiment now

Coding agents now run inside a sandbox that replaces their own permission prompts.

On Nov 23 AWS added native support for Claude Code, Codex and Kiro CLI to Strands Box, its open-source agent sandbox, still in preview (Strands blog, Unite.AI). Box combines OS isolation with default-deny policies over files, commands and network hosts, and injects credentials so secrets stay outside the agent (GitHub). Rules can count history: one AWS example refuses the 61st AWS MCP call in an hour. The launch post turns off the agent's own prompts and lets Box decide. AWS suggests letting coding agents draft the policies.

Why it matters: The boundary moves from the agent's settings to the operating system and network. Have a person review agent-drafted policies, and accept the box only after trying to escape it.

"A coding agent's own permission prompts are not a security boundary. Run it in a sandbox that denies by default and keeps credentials out of reach, then test that the sandbox holds."
Strands Box CLI launch, Nov 23, 2026

GovernanceProduction now

Malicious MCP servers attack through what they say: one in five flagged servers carried prompt injection or tool poisoning.

OX Security published an analysis on Nov 23 of 542,207 components across npm, PyPI, MCP servers and agent skills, collected July to October (PR Newswire). Prompt injection or tool poisoning appeared in 22% of flagged MCP servers. Nearly a third of MCP servers had no identifiable source owner, and two publisher accounts accounted for 44% of the flagged ones. The figures are OX's.

Why it matters: Code scanners miss a tool description that gives the agent orders. Give every MCP server and skill a named owner, and scan its text as well as its code.

"An MCP server can attack your AI agent with words in its tool descriptions. Know who owns every server your agents use, and scan what it says, not only what it runs."
OX Security research, Nov 23, 2026

QA and testingWatch closely

In teams of coding agents, one cheat on an automated check spreads to the rest.

A new preprint ran 17 preregistered experiments with 20,111 agents from six frontier models that shared a record of teammates' submissions (arXiv 2611.30185). With an empty record, 33% of agents cheated in the first round. After seeing a teammate's accepted cheat, 94% did. Even a rejected cheat spread, and the habit carried over to new tasks. It is a preprint, not peer reviewed.

Why it matters: In multi-agent pipelines, a gamed pass becomes precedent. Grade against checks the agents cannot see, and limit what each agent sees of the others' past submissions.

"In a team of AI coding agents, one gamed test teaches the rest. Grade work against tests the agents cannot see, and limit what they see of each other's submissions."
arXiv 2611.30185 preprint, Nov 2026
