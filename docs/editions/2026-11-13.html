Main signal

QA and testingExperiment now

Agent-built software is being accepted on evidence against a real reference, not on someone reading the code.

AWS released AWS Emulator (Nov 11), a free local stand-in for more than 200 AWS services that runs in CI with no AWS account (GeekWire, MarkTechPost). Coding agents wrote fidelity tests, ran them against real AWS, then built until the emulator matched status, body, error and resulting state. GeekWire reports that no engineer reviewed the code.

The scores ship with it: v1.0.322 matches real AWS on about 56.6% of roughly 42,900 tests, from under 20% for CloudFormation to over 90% for KMS. An IDC analyst notes it does not simulate throttling or outages, and does not sandbox the code it runs.

OpenAI applied the same logic to security on Nov 12: Daybreak Red Team (early access) has agents build working exploits, then rerun them after a fix to confirm it holds, while Defense Factory drafts patches for engineers to review (IT Daily, GBHackers). No benchmarks were published; figures are vendor-reported.

Why it matters: When nobody reads the code, the reference test is the control. Point agent tests only at emulated services with high fidelity scores.

"Software written by agents should ship with a score against the real system it imitates. AWS's agent-built emulator matches real AWS on about 57% of its tests, and says so."
AWS Emulator coverage, GeekWire and MarkTechPost, Nov 11 to 12, 2026

More signals

GovernanceProduction now

Claude Code 2.1.323 stops several settings errors from quietly loosening the sandbox.

Claude Code 2.1.323 (Nov 12) fixes claude -p and the Agent SDK running Bash unsandboxed when sandbox settings failed validation; it now stops at startup and names the bad setting. Unavailable auto mode now starts in Manual instead of a looser mode. It also fixes the sandbox switching off mid-session, Write and Edit reaching Read-denied paths, and deny rules missed through sudo and env wrappers.

Why it matters: Each was a fail-open path. Upgrade, then add CI tests with a corrupt sandbox setting and a sudo-wrapped denied command.

"A typo in a coding agent's sandbox settings should stop the job, not run it without a sandbox. Test that it does."
Claude Code 2.1.323 release notes, Nov 12, 2026

Engineering flowWatch closely

Cursor lets teammates' coding agents negotiate overlapping work before it reaches a pull request.

Cursor Projects became multiplayer on Nov 10, in beta. Teammates' coordinator agents exchange plans and flag overlapping work, and a decision made in one chat becomes context for every agent on the project. Cursor has published no failure rates or controls for it.

Why it matters: One wrong decision now reaches every agent. Treat project context as reviewed configuration, with an owner and a history.

"When coding agents share one project memory, a mistaken decision in one chat becomes every agent's instruction, so give that memory an owner and a review."
Cursor, Projects is now multiplayer, Nov 10, 2026
