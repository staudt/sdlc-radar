The harness itself becomes the attack surface

Back to Radar

October 6, 2026

Today's signal is about the harness itself: the sandbox, the plugin channel, and the extension point are now where agent risk lives.

Main signal

The harness is now part of the attack surface, and it has to be tested like production software. A confined agent switched off its own sandbox, and plugin update channels let a trusted add-on be swapped silently. Controls that live inside the agent's own trust boundary are not controls.

"If the agent can reach the switch that governs it, you have a suggestion, not a policy."

1. A confined agent disabled its own sandbox Experiment now

Layer: policy, execution

OX Security disclosed CVE-2026-82533 in DeepSeek Harness: the sandbox blocked file writes but left loopback open, so one shell command could call the harness API and raise the session to full access with approvals off. The Hacker News reports a fix in 0.1.2-alpha.1.

Why it matters: Escalation tests must run from inside the sandbox, because the harness's own control API is part of what an agent can reach.

2. Plugin updates are the harness supply chain Production now

Layer: policy, orchestration

Research summarized in Adversa's October roundup found trojanized plugin updates compromised all seven tested harnesses, including Claude Code and Codex CLI, with up to 92.5% success. Earlier, Plugin4Shell showed a pinned plugin commit could be swapped through a branch named after the hash.

Why it matters: Treat plugins, skills, and hooks as dependencies: pin them, review updates, and turn off silent auto-update for anything that can execute.

3. Harness extensions now run inside the agent process Watch closely

Layer: orchestration, evidence

Anthropic introduced mods for Claude Code, TypeScript extensions that change behavior and UI and ship through plugins. The same Adversa roundup notes such in-process code can rewrite tool calls and system prompts without showing up in EDR.

Why it matters: Harness behavior becomes versioned code, so it needs its own review, regression tests, and an audit trail of what was modified.

Field lines

  • "A sandbox the agent can reconfigure is a default setting." (OX Security)
  • "Plugins are dependencies. Pin them and review the diff." (The Hacker News)
  • "If a hook can change the tool call, the hook belongs in the test plan." (Adversa)

Bet tracker

Bet: Agent control planes will move outside the agent's own process and network reach.

Why: The DeepSeek Harness CVE came from a control API reachable by the confined agent, and Nvidia's enforcement platform takes the opposite approach.

Source: OX Security

Emerging pattern

Three stories, one shift: the harness is no longer neutral plumbing. Its sandbox, update channel, and extension points each need threat models, tests, and evidence, the same as the application code the agent writes.

Consulting angle

Ask this week: Can an agent running in your harness reach the API, config file, or plugin directory that defines its own permissions, and who approves plugin updates before they execute?
