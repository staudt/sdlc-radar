Safeguards under stress: patched redaction, strict resume, and tools that stop on cancel

Back to Radar

November 5, 2026

Today's theme is whether the safeguards around an agent run still hold when a run is cancelled, resumed, or fed hostile input: Pydantic AI patched ten advisories in its own tool, redaction, and tracing code, LangGraph can now refuse a stale approval answer on resume, and Gemini CLI stops tool calls after a cancel, which decides whether a crafted input, an old answer, or a stopped run can still touch your code and credentials.

Main signal

The controls around an agent are software with their own bugs and their own stale state. Pydantic AI 2.66.0 (Nov 4) fixes ten advisories, including a secret-redaction pattern that crafted text could make backtrack exponentially and embedding trace spans that recorded request headers and could expose credentials. LangGraph 1.2.20 (Nov 5) adds a mode that refuses an approval answer meant for an earlier pause, and Gemini CLI v0.67.0 (Nov 4) blocks tool calls after a cancel in non-interactive runs. A redaction filter that stalls, a trace that stores keys, or an old yes that still approves leaves source code and credentials open to whoever controls the input.

"An agent's redaction, approval, and cancel controls are code that fails like any other code, so they need their own adversarial tests."

1. Pydantic AI patches ten advisories in the agent's own safeguards Production now

Layer: policy, evidence

Pydantic AI v2.66.0 and v1.107.10 (Nov 4) fix two high-severity advisories, a web fetch tool that re-indented deeply nested JSON on the event loop and a private_key redaction pattern in the Pydantic AI Harness that backtracked exponentially (fixed in harness 0.66.0). Medium ones include embedding spans that recorded extra_headers and extra_body into traces, a default MCP capability ID built from the server URL that could leak path credentials to chat frontends, and reloaded message history that could rebuild tool-returned JSON as file objects and read s3:// objects with the app's credentials. The release also adds Workspace.authority for workspaces the operator does not control, and FunctionToolset(requires_approval=True) now applies to Tool instances passed to the toolset.

Why it matters: Upgrade, rotate any credentials that reached traces or MCP URL paths, and re-check which calls pause for approval in toolsets that pass Tool instances.

2. LangGraph can refuse an approval answer that belongs to an earlier pause Experiment now

Layer: policy, orchestration

LangGraph 1.2.20 (Nov 5) adds a strict resume mode that refuses stale interrupt answers and gives each interrupt() call within a task its own ID. langgraph-sdk 0.4.13 adds a cancel_reason field to Run. I read the release page, not the code, so how strict mode matches an answer to its pause is unverified.

Why it matters: A human approval only means something if it is tied to the question it answered, so add a test that replays an old answer after the pause has changed and expects a rejection.

3. Gemini CLI stops tool calls after a cancel and treats a spend cap as final Experiment now

Layer: execution, policy

Gemini CLI v0.67.0 (Nov 4) handles termination signals and blocks tool execution after cancellation in non-interactive mode, stops continuation stream processing and auto-nudging after a cancelled request, and classifies project spending cap errors as terminal quota errors. ACP permission requests now carry MCP server and tool metadata. The release page lists pull request titles only, and I did not read the code.

Why it matters: A pipeline timeout or cancel should end an agent's side effects and a spend cap should end the run, so test that a cancelled headless job makes no further tool calls and does not retry past the cap.

Field lines

  • "Redaction, tracing, and approval code in an agent framework is attack surface, so patch it on the same schedule as the model client." (Pydantic AI v2.66.0 release notes)
  • "An agent approval should be tied to the question it answered, because an old yes that can approve a new pause is a standing permission." (LangGraph 1.2.20 release notes)
  • "A cancelled or budget-capped agent run should end its tool calls, and a delivery pipeline should test that it does." (Gemini CLI v0.67.0 release notes)

Consulting angle

Ask this week: If someone replays an old approval, cancels a run mid tool call, or sends text built to stall your redaction filter, which of your agent controls still holds, and where is the test that proves it?
