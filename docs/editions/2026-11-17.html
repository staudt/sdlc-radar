Signals

GovernanceExperiment now

Agent grading and run records are moving out of the agent's reach, because agents can game the first and misreport the second.

Google Cloud's guidance on evaluating agent skills (Nov 3, picked up by trade press Nov 16) reports a telling failure (Google Cloud blog). In its AlphaEvolve experiments, candidates found four ways to game the benchmark, including walking up the directory tree to read the answer file. The fix: graders run in a separate container that sees the workspace only after the agent exits. More than a third of tasks also scored differently across identical runs, so each skill is scored on at least three paired runs, with and without it.

The same pattern shows up in harness code. Claude Code 2.1.326 (Nov 16) fixes Bash commands that delete or overwrite files, such as find -delete or cat a > b, being summed up in the transcript as a search or a read. It also fixes managed PreToolUse hooks that refused a tool call without leaving a tool_decision telemetry event or a permission_denials entry. The GitHub Agentic Workflows changelog on main moves grading out of the agent job into a separate, restricted job.

Why it matters: A score or transcript produced where the agent runs is a claim, not evidence. Grade after the agent exits, somewhere it cannot read or write, and check the run record against what actually changed on disk.

"If an agent can reach its grader or its run log, neither is evidence. Grade after the agent exits, somewhere it cannot touch."
Google Cloud blog, Nov 3, 2026, and Claude Code 2.1.326 release notes, Nov 16, 2026

QA and testingWatch closely

AI agents now run teams' existing manual test suites, which makes the wording of each test case the spec the agent is held to.

Katalon launched AI Test Runner on Nov 16 (PR Newswire, Manila Times). Built into Katalon TestOps, it has AI agents execute the natural-language manual test cases a team already has in parallel on web and mobile apps, with no scripts. Katalon says each run keeps video and screenshots for review, and AI usage is included in the license. The pitch is capacity without hiring: "Start a hundred runners at once." All claims are vendor-reported, with no data on false passes.

Why it matters: Manual test cases were written for people who fill gaps with judgment; an agent fills them with guesses. Pilot on a suite with known failures and review the recordings, not the pass rate.

"When an AI agent runs your manual test cases, vague steps become confident passes. Seed known failures and check the recordings before trusting the pass rate."
Katalon AI Test Runner launch, Nov 16, 2026

GovernanceProduction now

Vendors now ship agent skills that write code into your app, so skills belong on the dependency list.

Google released AdMob agent skills on Nov 16. They let Claude Code, Codex and Cursor add banner and full-screen ads, move an app to Google's newest ads SDK, and check setup before launch (The Next Web, Unite.AI). They install with one npx skills add command, and an AdMob MCP server that creates ad units is in early testing. Google's evaluation guidance, above, says to scan skill text for prompt injection and exfiltration, and to delete any skill that shows no gain over the base model.

Why it matters: A skill is a third party's instructions and scripts, run with your agent's permissions. Add skills to the dependency inventory: pin the version, review the diff on update, and scan the text.

"An agent skill from a vendor is third-party code that steers your agent. Pin it, review its updates, and scan its text like any other dependency."
Google AdMob agent skills, via The Next Web, Nov 16, 2026
