Approvals move into the harness: fail-closed review, fresh-approval rules, and agent tests without a live model

Back to Radar

November 6, 2026

Today's theme is who decides what an agent may run: Copilot CLI 1.0.106 and Codex 0.167.0 reached stable with approval, network, and sandbox controls that fail closed or demand a fresh human yes, and an OpenAI agent SDK preview adds tests that run with no live model, which decides whether a script, a network call, or a tool the agent runs on your code and credentials was ever checked by anyone.

Main signal

Approval logic is moving out of the prompt box and into rules the harness enforces. Copilot CLI 1.0.106 (Nov 5 to Nov 6) requires explicit approval for scripts it cannot fully parse and makes its assisted-mode judge fail closed before dispatch when a request is too large. Codex 0.167.0 (Nov 6) documents managed network constraints and prompt-user command rules that require fresh human approval. A command that slips past a parser or an approval that was never asked for runs on your source code and credentials with nobody having said yes.

"An agent approval should fail closed: when the harness cannot parse a script or judge a request, the answer is no until a person says yes."

1. Copilot CLI 1.0.106 goes stable with fail-closed approvals and a sandboxed extension setting Experiment now

Layer: policy, execution

Copilot CLI v1.0.106 (Nov 6) turns the pre-release changes into a stable build: scripts it cannot fully parse need explicit approval, rejecting one tool in a parallel batch cancels its sibling prompts, and assisted mode fails closed before dispatch if the judge request exceeds the model's context. It also adds a Sandbox extensions setting that runs extension processes inside the sandbox, glob patterns in sandbox deny rules, and warnings when untrusted folders skip repository hooks or workspace MCP servers. --yolo and --allow-all now apply when resuming a local session, so check that behavior against your own pipelines.

Why it matters: Rerun your approval and sandbox test cases on the stable build, including one that resumes a session with a blanket-approval flag and one with a script the CLI cannot parse.

2. Codex 0.167.0 documents rules that force a fresh human approval Experiment now

Layer: policy, orchestration

Codex 0.167.0 (Nov 6) documents managed network constraints under [permissions.network] and prompt-user command rules that require fresh human approval. It closes network approval prompts when their requests end and prompts one at a time for concurrent requests to the same endpoint. The changelog also lists per-chat leases for shared MCP connections and Guardian review of recorded exec calls; I read the release notes and PR titles, not the code, so how Guardian decides is unverified.

Why it matters: A rule that always asks a person is a control you can test, so write one case that expects a prompt for a risky command and fails the job if it runs silently.

3. Playwright 1.65.0 adds failure-only reports and stricter checks that can break your suite Production now

Layer: verification, evidence

Playwright v1.65.0 (Nov 5) adds a failures reporter and an onlyFailures option for the HTML, JSON, and JUnit reporters, a built-in -exclusive- lock, and Bun support for the test runner. A sharded run now fails when no tests match across all shards unless --pass-with-no-tests is passed, actions wait for elements to stop being inert, and text the browser does not render is dropped from accessible names and aria snapshots. The release page shows no year, so I took 2026 from the page footer.

Why it matters: The no-match shard failure and the accessible-name change can turn a green agent-run suite red or change snapshot matches, so upgrade on a branch and read the diff before you trust the first result.

Bet tracker

Strengthening: Agent control planes will move outside the agent's own process and network reach. Copilot CLI 1.0.106 tells users to contact an administrator on managed sandbox policy errors, and Codex 0.167.0 documents managed network constraints, so policy owned by the organization, not the session, keeps spreading (Copilot CLI v1.0.106, Codex 0.167.0).

Consulting angle
