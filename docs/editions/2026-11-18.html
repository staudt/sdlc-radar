Signals

GovernanceProduction now

Attackers now plant instructions for coding agents in the repositories developers clone.

Bitdefender Labs reported a campaign on Nov 17 built from 22 malicious GitHub links (Bitdefender, GBHackers). Poisoned AGENTS.md and CLAUDE.md files tell the assistant to run scripts/setup.js, and to run it without asking if the user asks for help before setup. A second route needs no model at all: a session-start hook in .claude/settings.json launches the same script once the developer trusts the project.

The script steals GitHub, GitLab and cloud credentials and searches the home directory for AI tool settings. Where stolen tokens allow, it commits poisoned AGENTS.md, CLAUDE.md, .mcp.json and VS Code task files into the victim's other repositories. Bitdefender does not say how many developers ran it. SafeDep reported the same pattern in 12 repositories on Nov 9: forged commits carrying a setup script plus instructions that discourage reading it (Gridinsoft).

The trust prompts Codex, Claude Code and GitHub Agentic Workflows shipped last week (Monday edition) are the right control, as long as developers stop clicking Trust by reflex.

Why it matters: Instruction files and hooks are now code that runs on a developer's machine with that developer's credentials. Review them before trusting an unfamiliar repo, and put AGENTS.md, CLAUDE.md, .mcp.json and hook settings under the same review rules as CI workflow files.

"A cloned repository can carry instructions that tell a coding agent to run malware. Review a repo's agent files before anyone trusts it, the same way you review its CI pipeline."
Bitdefender Labs, Nov 17, 2026

GovernanceExperiment now

Microsoft now treats coding agents on developer laptops as endpoints to inventory, identify and watch.

At Ignite on Nov 17, Microsoft said Defender and Entra Global Secure Access together discover more than 60 local AI agents, including Claude Code and GitHub Copilot CLI, along with the MCP servers each is configured to use (Agent 365 at Ignite). Entra Agent ID gives each discovered agent its own identity, separate from the developer's, in preview. Defender runtime protection, in public preview, inspects prompts, tool calls and tool results from outside the agent, starting with Claude Code and Copilot CLI (Defender docs). Status differs by feature and Microsoft docs still mark discovery as preview, so check before promising it to a client.

Why it matters: Most clients cannot say which agents run on developer machines or which MCP servers they reach. A separate agent identity lets policy and audit follow the agent, not the developer's account.

"You cannot govern coding agents you cannot list. Inventory every agent and MCP server on developer machines before writing policy for them."
Microsoft Agent 365 and Defender announcements at Ignite, Nov 17, 2026

QA and testingWatch closely

AI security testers now publish how often they stay in scope, and the number is not 100%.

Microsoft opened an invite-only preview of its Web App Pen Test Agent at Ignite on Nov 17 (Microsoft Security blog, benchmark post). It attacks an authorized web app and reports evidence, affected endpoints, severity and a proof of concept for each finding. In Microsoft's benchmark with Incalmo, it solved 31.0% of tasks on average against 15.2% for Codex, which ran without the production guardrails, and stayed within testing boundaries in 91% of safety-constrained tests. All figures are Microsoft's.

Why it matters: Run agentic pen tests only where the network enforces the scope, and accept a finding only with its proof attached.

"An AI pen tester that stays in scope 91% of the time still leaves it about once in eleven runs. Enforce the boundary in the network, not in the agent's instructions."
Microsoft Perception benchmark, Ignite, Nov 17, 2026

Also in the news

  • Claude Code 2.1.327 (Nov 17) lists ignored permission settings, hook matchers that never match and an unavailable sandbox in /status, and claude mcp add-json now reads server JSON from stdin so tokens stay off the command line.
  • Copilot CLI 1.0.113 (Nov 17) lets administrators turn off built-in Browser Use with the managed setting features.browserUse, including in running sessions.
  • Microsoft's Ignite Book of News lists GitHub Copilot agent governance rulebooks and bring-your-own-model support in CLIs and IDEs as generally available; it gives few details on what the rulebooks enforce.
