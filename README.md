# SDLC Radar

A living view of current AI software development, modern SDLC practices, QA, and test automation.

## What this repository contains

* `docs/index.html` contains the main dashboard style landing page.
* `docs/topics/` contains deeper topic pages.
* `docs/editions/` contains archived daily editions.
* `docs/about.md` explains the purpose and structure.

## Publishing

This repository is intended to be published through GitHub Pages from the `docs/` folder on the `main` branch.

## Model

The site separates:

* **Editions**: time based archive of daily observations
* **Current state**: continuously updated view of the market
* **Topics**: deeper pages for specific areas such as testing, agentic SDLC, evaluation, and governance
